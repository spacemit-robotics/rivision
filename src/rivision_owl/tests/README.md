# RiVision-OWL 测试方案

## 测试架构

```
┌─────────────────────────────────────────────────────────────────────┐
│                          端到端测试 (E2E)                            │
│  gb28181-sim → OWL (SIP) → ZLMediaKit (RTP) → 视频播放验证           │
└─────────────────────────────────────────────────────────────────────┘
                              │
┌─────────────────────────────┼─────────────────────────────────────────┐
│                         集成测试                                      │
│  ┌───────────────┐  ┌───────────────┐  ┌───────────────┐             │
│  │ SIP 信令测试   │  │ RTP 流测试    │  │ API 接口测试   │             │
│  └───────────────┘  └───────────────┘  └───────────────┘             │
└─────────────────────────────────────────────────────────────────────┘
                              │
┌─────────────────────────────┼─────────────────────────────────────────┐
│                         单元测试                                      │
│  ┌───────────────┐  ┌───────────────┐  ┌───────────────┐             │
│  │ SIP 解析测试   │  │ SDP 解析测试   │  │ 媒体处理测试   │             │
│  └───────────────┘  └───────────────┘  └───────────────┘             │
└─────────────────────────────────────────────────────────────────────┘
```

## 测试级别

### Level 1: 单元测试
- SIP 消息解析/构建
- SDP 解析
- Digest 认证计算
- 通道配置解析

### Level 2: 集成测试
- gb28181-sim 与 OWL SIP 信令交互
- OWL 与 ZLMediaKit RTP 流转发
- OWL HTTP API 功能

### Level 3: 端到端测试
- 完整注册流程
- 视频点播流程
- 多通道并发测试
- 断线重连测试

## 运行测试

```bash
# 单元测试
./run_unit_tests.sh

# 集成测试 (需要 OWL 运行)
./run_integration_tests.sh

# 端到端测试 (需要完整环境)
./run_e2e_tests.sh

# 全部测试
./run_all_tests.sh
```
