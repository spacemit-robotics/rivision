┗━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┛

  ┌──────────────────────────────────────────────────────────────────────────┐
  │ 1. 环境变量                                                                  │
  │    • YOLO_THREADS=4           NPU 核心数 (4 核可用)                          │
  │    • YOLO_DUAL_SESSION=1      启用双 Session (默认开启)                        │
  │    • FFMPEG_MULTI_INSTANCE=4  FFmpeg 多实例解码 (默认 4)                    │
  │    • CPU_THREADS=4            CPU 线程数 (预/后处理)                        │
  ├──────────────────────────────────────────────────────────────────────────┤
  │ 2. 性能优化建议                                                            │
  │    • 当前配置 (4核×2) 已达 56 fps，接近理论极限                            │
  │    • 8核配置 (4×2 Session) 理论可达 80-100 fps                           │
  │    • 降低分辨率 640→512 可提升约 30% FPS                                   │
  ├──────────────────────────────────────────────────────────────────────────┤
  │ 3. 模型选择建议                                                            │
  │    • 实时监控: yolov8n/yolov5n (56 fps)                                    │
  │    • 平衡选择: yolo11n (47 fps)                                             │
  │    • 高精度: yolov8m (20 fps, 适合小目标)                                  │
  └──────────────────────────────────────────────────────────────────────────┘

  ┌──────────────────────────────────────────────────────────────────────────┐
  │ 【延迟 (Latency)】                                                           │
  │                                                                          │
  │  定义: 从输入一帧图像到输出检测结果的总时间                                  │
  │                                                                          │
  │  延迟 = 预处理 + NPU推理 + 后处理                                            │
  │         (~6ms)   (~35-100ms)  (~3ms)                                     │
  │         解码缩放   前向传播   NMS过滤                                         │
  │                                                                          │
  │  对实时视频流的影响 (@30fps 视频源):                                         │
  │  ┌──────────┬────────┬──────────────────────────────────┐               │
  │  │ 延迟     │ 帧延迟 │ 实际影响                         │               │
  │  ├──────────┼────────┼──────────────────────────────────┤               │
  │  │ <50ms    │ 1-2帧  │ 几乎无感知，适合实时监控/交互   │               │
  │  │ 50-100ms │ 2-3帧  │ 略有滞后，适合视频分析/录像   │               │
  │  │ >200ms   │ 5-6帧  │ 明显延迟，仅适合离线批处理    │               │
  │  └──────────┴────────┴──────────────────────────────────┘               │
  │                                                                          │
  │  注: 本测试 yolov8n 延迟 49ms ≈ 1.5帧延迟，适合实时应用                     │
  │      延迟影响响应速度(报警触发)，FPS影响处理路数                             │
  └──────────────────────────────────────────────────────────────────────────┘
